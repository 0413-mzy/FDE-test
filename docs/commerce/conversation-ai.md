# 商家会话 AI 辅助

本轮仅处理当前店铺中已授权的单一会话。商家在消息页面手动生成或更新，
DeepSeek 提供中文客户诉求、明确条件、商家承诺、未解决事项和建议回复。
回复由商家检查、修改，并通过原消息发送按钮提交。AI 没有任何业务执行工具。

## 资料与结果

后端读取完整的当前消息快照，按来源角色和顺序分析。长对话先分段，再合并；
超过服务端输入限制会明确拒绝，不把截断内容标成完整摘要。结果保存来源编号、
覆盖消息数量、内容指纹、模型和提示词版本、生成时间以及实际 token 用量。
新消息出现后，旧摘要会标记待更新。新生成失败保留旧成功结果。

只传会话消息正文、角色和来源编号；不传账户密码、数据库连接信息、地址簿或整库。
可识别的邮箱、电话和密钥会先遮盖，但不能保证识别所有个人信息。用户界面提示
会话会交由 DeepSeek 处理。公共演示请只使用虚构资料；共享演示账号可由其他访客使用。
模型输出仍需人工核对，来源编号校验不能证明每个自然语言判断都正确。

## 权限与请求

GET 和 POST 使用路径：

```text
/api/commerce/v1/merchant/shops/{shop}/conversations/{conversation}/ai-assistance
```

GET 读取是否可用、最近成功结果、最近生成尝试及是否陈旧。
POST 接受空 JSON 对象和 `Idempotency-Key`，由后端选择消息，不接收前端提供的模型指令。
活跃本店商家成员才可使用；客户、DEMO 和非本店商家不能查看或触发生成。
模型调用前后都检查权限，调用期间不持有业务写锁。

同一消息快照复用已有成功结果；同一会话限制并发，过期任务可恢复。
新的幂等键创建缓存请求也受账户和全局访问限制；同一键的原请求重放不新增记录。
AI 月预算没有固定金额上限，但并不意味着单次请求无限长，
或公共演示可无限并发调用。外部调用不进行无法确定计费结果的无限重试。

## 私密配置

后端配置 `DEEPSEEK_API_KEY` 和可选的 `DEEPSEEK_MODEL`，默认模型为 `deepseek-flash`。
密钥缺失时功能不可用；密钥不进入前端或 Git。不要把真实密钥写入 `.env.example`。
密钥已出现在聊天中，建议更换后用于公开服务。Render/Neon 继续采用免费资源。

真实模型评估入口：

```sh
python scripts/commerce-ai-evaluation.py --scenario all --output /private/path/ai-evaluation.json
```

先以私密环境变量配置密钥。评估会调用真实 DeepSeek 并产生用量，使用仓库内固定的
虚构对话，不读取业务数据库，不发送消息。输出包含人工核对标准、实际结果和 token，
不是自动证明摘要正确的评分器。API 认证失败、余额不足、限流、超时和输出校验失败
会报告失败，不以模拟答案冒充真实模型成功。
