# 私有只读数据中心设计

用户2026-10-07批准私有、只读、可每15秒刷新方案并要求开始。
入口集成现有网站，使用现有私有platform资格；共享customer/owner/staff/demo/dual账号拒绝。
后端GET API读取允许的商城业务表和AI尝试，不允许SQL、任意schema、密码/令牌/验证表、图片二进制。
使用明确字段白名单，历史快照也二次投影到同一白名单；不暴露连接字符串、数据库凭据或完整技术表。

页面包含中文数据目录与数量、环境标签、分页记录、更新时间、ID/姓名/正文关键字搜索、状态/日期筛选。
记录详情展示字段说明与关联记录链接；订单可访问支付、物流、对话、售后，AI尝试可回溯会话。
历史按记录展示时间、操作、操作者、原因、修改前后字段；支持全局时间/操作者/操作筛选。
BASELINE明确为升级当时基线，不恢复不存在的过去。删除记录通过历史仍可访问。
AI尝试保存自身生命周期，不将其伪称为全行版本历史。
时间显示马来西亚时间并保留ISO值；金额展示币种与分值。

只读事务、参数化过滤、固定表/列注册、最多100行分页、稳定排序、查询超时与安全错误。
自动刷新默认关闭，启用后15秒一次，仅当前页面可见且无在途请求时刷新，停止后清理定时器。
显示最后成功读取时间，失败保留明确错误和重试入口，不把旧数据称为刚刚更新。
不新增业务写接口，不改变现有订单、库存、消息、密码或历史触发器；若不需要索引无需迁移。

验收包含真实隔离PostgreSQL权限拒绝、恶意表/查询输入、白名单及秘密不输出、实际修改后当前值/历史可读、
删除/基线/AI语义、分页过滤、只读事务。前端测试/lint/type/build及实际浏览器筛选/详情/历史/刷新。
GitHub候选PR不合并main；公网发布只在通过检查后执行现有免费服务，不创建资源或公开私密账号。
